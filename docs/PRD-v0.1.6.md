# ZJPanel PRD 变更 v0.1.6

> 提出人：阿杰（HUMAN，甲方代表）｜整理：产品经理 QJM5｜日期：2026-11-10
> 触发：验收 v0.1.5 时提出「终端各功能弄好了吗？页面响应式 主题深浅」，确认「处理」后立项。
> 说明：响应式与深浅主题不在原始 PRD（PRD.txt）范围内，属新增需求；终端回显为存量缺陷修复。

## 一、需求范围

### 1. 终端功能修复（缺陷）
- 现状：终端功能齐备（SSH 主机增删改/连接测试、本地终端、多标签、会话常驻后端、刷新恢复+回放、窗口 resize）。
- 缺陷：`/api/ws/terminal` 的 `create` 分支创建会话后未将当前 WebSocket 注册为输出客户端，导致**新建会话可输入、命令实际执行，但屏幕无实时回显**；用户必须刷新页面走 `attach` 后才能看到输出。
- 要求：新建 SSH/本地会话后，创建者立即收到实时输出；`attach` 恢复会话行为保持不受影响。

### 2. 页面响应式（新增）
- 现状：侧栏固定 220px、表格/弹窗固定宽度，全项目无媒体查询/断点，窄屏挤压溢出。
- 要求：
  - 断点：≥768px 桌面保持现有左右布局；<768px 移动端侧栏改为抽屉（汉堡按钮展开、点菜单/遮罩自动收起）。
  - 内容区：窄屏减少外边距；表格允许横向滚动而非撑破布局；弹窗宽度按视口自适应（如 `min(860px, 96vw)`）。
  - 终端页：横屏/窄屏下 xterm 高度自适应，窗口尺寸变化时重新 fit。

### 3. 主题深浅（新增）
- 现状：侧栏/菜单写死深色、顶栏写死白色，无主题切换能力。
- 要求：
  - 提供「浅色 / 深色 / 跟随系统」三态切换，入口在顶栏，选择本地持久化（localStorage），刷新后保持。
  - 通过 Ant Design Vue ConfigProvider 的 algorithm 全局切换组件主题；`html/body` 背景色、顶栏、文字颜色联动。
  - 终端 xterm 配色联动：浅色主题用亮色终端配色，深色主题用现有深色配色；主题切换即时生效于已打开的终端。
  - 代码编辑器（AceEditor）配色联动：浅色用 chrome，深色用 terminal。

## 二、交互流程
1. 顶栏新增主题切换按钮 → 下拉选择浅色/深色/跟随系统 → 即时生效并写入 localStorage。
2. 跟随系统：监听 `prefers-color-scheme` 变化，系统主题改变时自动切换。
3. 移动端：顶栏左侧出现汉堡按钮 → 点击展开抽屉侧栏 → 点击菜单项跳转并自动关闭抽屉。
4. 终端：新建会话 → 输入命令 → 立即看到回显（无需刷新）。

## 三、验收标准
| # | 场景 | 预期 |
|---|------|------|
| 1 | 新建本地/SSH 会话后输入 `echo test` | 屏幕立即显示 `test`，无需刷新页面 |
| 2 | 刷新终端页 | 会话标签与历史输出经 attach 回放恢复，不受修复影响 |
| 3 | 顶栏切换浅色/深色 | 全站组件、背景、侧栏即时切换；刷新后保持选择 |
| 4 | 选择「跟随系统」并改变系统主题 | 界面自动跟随切换 |
| 5 | 主题切换时终端/编辑器已打开 | xterm 与 Ace 配色同步变化 |
| 6 | 视口宽度 <768px | 侧栏收为抽屉，表格横向滚动，弹窗不溢出，页面无水平滚动条 |
| 7 | ≥768px 桌面 | 布局与操作保持与 v0.1.5 一致 |

## 四、非范围（本轮不做）
- 不改变原有业务逻辑与 API 契约（无新增后端接口，`create` 修复仅补注册输出客户端）。
- 不做移动端专属页面/手势、不做多套配色自定义（仅浅/深/跟随系统三态）。
- 不调整 SSH 主机测试数据（容器内 127.0.0.1:22 未开 sshd，连接测试返回 refused 属环境数据问题）。

## 五、交付方式
沿用既定流程：代码提交 → push tag `v*` 触发 GitHub Actions 构建镜像 → 拉取新版本更新 /opt/zjpanel-debug 调试部署 → 按上表验收 → 汇报阿杰。
